# Barcrawl

Barcrawl is a collection log for every* food and drink in game, can you drink your way to glory?

<br>


### Disclaimer section:

Barcrawl is new and I can't promise it will keep collection data safely yet.

*The list is currently every item with "Eat" or "Drink" options, some items may be unattainable. 
If you find an item is unable to be consumed, please add it to the GitHub Issues.
